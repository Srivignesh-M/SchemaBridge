Source

Files are combined into one conversion in filename/path order (1, 2, … 10). Use prefixes such as 01-schema.sql and 02-data.sql to put definitions before data. All files must use the selected source dialect. Choosing files or a folder replaces the current SQL input.

Use Ctrl / Cmd to select multiple tables.

Destination

Every table gets an explicit action.

Existing tables are compared by columns, converted types, defaults and constraints. Matching tables can receive DML only. Mismatched tables remain skipped.

Supported first release

CREATE TABLE, literal INSERT values, primary/unique/foreign keys, common numeric, character and date/time types. Unsupported syntax is reported and blocks executable output.

Data loading is insert-only. Duplicate keys fail; existing rows are never silently replaced.

Transfer settings

Validation adds read time. Completed tables are retained after a later failure. A higher row limit is not a guarantee for every table shape.
